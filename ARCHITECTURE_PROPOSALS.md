# Architecture Proposals

Deviations from or extensions to `ARCHITECTURE.md`/`PLAN.md` are proposed
here first, with real reasoning, before implementation. See
`CONTRIBUTING.md`'s "Proposing an architecture change" for the process.
Each entry is resolved as `Resolved: Approved` (folded into `ARCHITECTURE.md`
or `PLAN.md`) or `Resolved: Rejected` (left here with reasoning, for the
record). No entries yet — this file is created empty alongside the initial
scaffold and will fill in as real design decisions get contested during
implementation.
